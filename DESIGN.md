# CareerGroove Design Specification

This document outlines the visual and interaction design requirements for CareerGroove.

**CODEX INSTRUCTION:** You MUST use your design "skills" (as outlined in AGENTS.md) to interpret and build the look and feel of this application. Do not generate a default Bootstrap or plain Tailwind template.

## 1. The Vibe
*   **Theme:** Whimsical, fun, action-oriented, but strictly professional in its data handling.
*   **Inspiration:** Think of a cozy video game menu crossed with a high-end productivity tool.
*   **Color Palette:** Muted but warm background tones with bright, energetic accent colors for primary actions (buttons, success states).

## 2. Interaction Design (Motion Skill Required)
*   **Animations:** Everything should feel tactile.
    *   Buttons should "press" down.
    *   Saving a new job should trigger a satisfying card flip or a subtle confetti burst using Framer Motion.
    *   Page transitions should slide or fade smoothly, behaving like a native mobile app (PWA).

## 3. The Audio Experience
*   **The Player:** A global, floating, or cleanly integrated UI component for background music.
*   **Controls:** Play, Pause, Skip, Volume.
*   **Selection:** Options for Lo-Fi, Ambient, Classical, or "Brain Waves" focus music.

## 4. Layout
*   **Mobile-First PWA:** Bottom navigation bars on mobile, collapsing sidebars on desktop.
*   **Data Entry:** Use "wizard" style conversational forms or the AI Interviewer chat interface rather than massive vertical forms.
